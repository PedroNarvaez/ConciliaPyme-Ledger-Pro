2. Dashboard y Conciliación Automática

El Dashboard principal se compone de tres paneles de datos (Ventas importadas, Extractos bancarios y Resultados de la conciliación) junto con controles del sistema en el margen izquierdo:

  1. Cargar Archivos Demo: Rellena automáticamente el Dashboard con datos reales paraguayos para su evaluación inmediata.
  2. Importar Ventas / Banco: Permite importar sus propios archivos. Soporta formatos CSV locales de bancos, MT940, CAMT.053 y SIFEN XML de Paraguay.
  3. Conciliar y Guardar: Aplica el motor de emparejamiento con tolerancias de fecha y monto y escribe la evidencia inmutable en la base de datos y ledger local.

3. Consulta de Cotización Divisas (Arbitraje)

En la pestaña "Cotización" se consultan las cotizaciones vigentes del dólar estadounidense frente al guaraní (USD/PYG) provistas en línea por la API de dolarpy. Cuenta con un calculador bidireccional para realizar arbitrajes usando la fuente seleccionada.

4. Seguridad y Auditoría Criptográfica

Tanto el ledger local de conciliaciones como el log de eventos de auditoría se encuentran encadenados mediante hashes SHA-256. Esto permite realizar una verificación matemática exhaustiva haciendo clic en "Verificar Integridad de Bitácora" o "Verificar Integridad Ledger" para comprobar que los datos no han sido adulterados por agentes externos.
