1. Introducción

ConciliaPyme Ledger Pro es una aplicación de escritorio para conciliación financiera automatizada, diseñada específicamente para PYMES paraguayas.

💡 Consejo: Use los datos demo para familiarizarse con la aplicación antes de importar datos reales.

5. Conciliación

El sistema compara automáticamente ventas contra movimientos bancarios usando:

  • Referencia de transacción
  • Cliente/Descripción
  • Fecha (con tolerancia configurable)
  • Monto (con tolerancia configurable)

7. Auditoría

Todos los eventos quedan registrados con hash encadenado SHA-256:

  • Logins exitosos y fallidos
  • Importaciones de datos
  • Ejecuciones de conciliación
  • Exportaciones de reportes
  • Verificaciones de ledger
  • Backups creados/restaurados
🔒 Seguridad: Puede verificar la integridad de la auditoría en cualquier momento. El sistema validará toda la cadena de hashes.

8. Backup y Restauración

Para crear backup:

  1. Menú Archivo → Backup
  2. Seleccione ubicación de guardado
  3. Ingrese clave de cifrado
  4. El archivo se guardará como .cplybak
⚠️ Advertencia: Sin la clave correcta, no se puede restaurar el backup. Guárdela en lugar seguro.

10. Solución de Problemas

La aplicación no inicia

Solución: Verifique que Python 3.8+ esté instalado:

python --version

Error de login

Causas posibles:

  • Contraseña incorrecta
  • Cuenta bloqueada (espere 15 minutos)

Ledger muestra error de integridad

Solución: Restaure desde backup válido o contacte al administrador.
